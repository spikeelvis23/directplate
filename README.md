# DirectPlate

DirectPlate lets local restaurants take delivery orders straight from their
customers. It cuts out big delivery apps and their high fees, so restaurants
keep more of each order.

**Live demo:** https://spikeelvis23.github.io/directplate/

![DirectPlate screenshot](screenshot.png)

## Built with

- HTML
- CSS

## Run it locally

1. Clone the repo:
   `git clone https://github.com/spikeelvis23/directplate.git`
2. Open `index.html` in your browser.
